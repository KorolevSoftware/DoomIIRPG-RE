# 2026-08-23 — Doors: original mechanics vs rewrite (bug "doors work incorrectly")

## Hypothesis

The rewrite's door system (`new_src/domain/game/Game.cpp:98-371`,
`new_src/render/World3D.cpp:687-713`) diverges from the legacy reference
(`src/`) in trigger rules, animation axes and renderer consumption, which
explains the user report "doors work incorrectly".

## Verdict

PARTIAL — the rewrite reproduces the 750 ms scale lerp and the ±32 slide rule,
but misses the door-family split in the renderer (vertical "slip door" split for
tiles 271-274 vs horizontal slide for the rest), all UV compensation, the
script-driven unlock path for keycard doors, the faced-door use semantics, and
several solidity-timing details.

## Evidence (highlights)

* Door range & flags: `src/Enums.h:832-842`, `src/Enums.h:1228-1250`.
* performDoorEvent flow incl. locked refusal, monster-blocks-close, relink at
  close start, unlink at open end, frame switch to media frame 1:
  `src/Game.cpp:1053-1155`, completion side effects `src/Game.cpp:3120-3134`.
* Lerp math: `frac8 = (elapsed<<16)/(travelTime<<8)`; pos/scale =
  `src + (frac8*((dst-src)<<8)>>16)`; travelTime = 750:
  `src/Game.cpp:1127-1128,2862-2882`.
* Renderer door block: geometry forced to full size, real scale `n10` drives
  one-axis collapse; red/blue (271-274): height collapse + v-recenter +
  TWO stacked quads with gap `(origH - lerpedH)`; others: width collapse +
  u-shift by FULL delta: `src/Render.cpp:428-435,585-599,601-638`.
* Use action: eType 5 within Chebyshev 1 tile (`tileDistances[0]=4096`,
  `distFrom=max(dx²,dy²)`), locked ⇒ message 44 only, else open+advanceTurn:
  `src/PlayingInputHandler.cpp:445-459`, `src/Combat.cpp:42`,
  `src/Entity.cpp:1155-1158`.
* Keys are script-only: inventory[19]/[20] via EV_ITEM_COUNT then EV_DOOROP
  op1/op3 → `setLineLocked` flips tileNum bit 0 and re-looks-up def by
  tileNum+257: `src/Enums.h:222-223`, `src/Entity.cpp:172-175`,
  `src/ScriptThread.cpp:433-454,747-780`, `src/Game.cpp:2477-2498`.
  No native key check exists (`Player::requireItem` uncalled,
  `src/Player.cpp:253-262`).
* Auto-close each turn with occupancy checks on door tile + both neighbours
  along slide axis; snap if off-screen: `src/Game.cpp:1271-1278,1215-1236,1153-1155`.
* Collision: movement trace mask includes ET_DOOR bit (13501);
  oriented entities collide as ±32 wall segments at their animated position:
  `src/MovementController.cpp:326-333`, `src/Game.cpp:216-296`.
