# 2026-11-03: Original front-end flow (boot → main menu → new game → character select → map) and rewrite gap

## Hypothesis / questions
How does the original `src/` get from boot to gameplay: logo, intro movie, main menu rows,
New Game confirm 14, difficulty values 1/2/4 and their names (the task suggested 3:200-202),
character select (assets, layout, input, stats), prologue, `startGame(true)`, first map?
What do in-game "Main Menu" (42), Save & Quit and Don't Save return to? What does
`new_src/` already have, and what is missing?

## Method
* Read `src/App.cpp`, `src/CAppContainer.cpp`, `src/GameStateRunner.cpp` (logo, menuState),
  `src/Canvas.cpp` (run/setState/backToMain/paint), `src/IntroSequenceManager.cpp` (whole
  file), `src/MenuSystem.cpp` (`initMenu` main cases, `select`, `back`, `setMenu`, `paint`,
  `setMenuSettings`, `drawTouchButtons`, `drawScrollbar`, `startGame`, `SetYESNO`),
  `src/InputEventController.cpp`, `src/TouchController.cpp`, `src/Player.cpp`.
* `src/MenuSystem.cpp` is ISO-8859 + CRLF, so plain `grep` printed nothing. All greps
  there used `grep -a`.
* Decoded the shipped `menus.bin` rows 3/4/13-19/26/27/29/42/51 and strings types 0/2/3 from
  `build_new/new_src/Doom 2 RPG.ipa` with a throwaway read-only script in the session
  scratchpad. It uses the ADR 0013 row/item layout and the `new_src/io/Localization.cpp`
  index layout. I also read the BMP headers for asset sizes.

## Verdict
**CONFIRMED with corrections.** The flow is
`ST_LOGO` → `ST_INTRO_MOVIE` → `MENU_MAIN` → (confirm 14) → difficulty 16 →
`ST_CHARACTER_SELECTION` → `ST_INTRO` → `loadMap(1, false, true)`.

Corrections to the task's assumptions:
* **3:200-202 are not difficulty names.** They are the ranking headers "RANKING" /
  "DIFFICULT RANKING" / "NIGHTMARE RANKING" (`src/MenuSystem.cpp:3710-3718`). The
  difficulty labels are **3:207 "Nor-mal" (1), 3:208 "Dif-fi-cult" (2), 3:209 "Night-mare"
  (4)** in `menus.bin` row 16. The row title 3:206 "Choose Game Mode:" is skipped by
  `loadMenuItems(16,1,-1)` (`src/MenuSystem.cpp:1274-1281`).
* The main menu has **no "Help/About/Credits" rows of its own in the form assumed**. The
  rows are [Continue], New Game, Options, Comic Book, Mini Games, Game Help, About, Exit.
  "Other Games" is in the data but the port skips it (`:1266-1270`). Credits is the last row
  of Game Help (4).
* Character-select slot order is **Major, Scientist (Riley), Sarge** (constants 1, 3, 2;
  `src/IntroSequenceManager.cpp:325-339`).
* The port forces `hasSeenIntro = true` (`src/CAppContainer.cpp:188`), so the intro is
  always skippable by any key.
* `MENU_INGAME_SPECIAL_EXIT` 58 is unreachable in the port. `items[11]` is written past
  `numItems` (11) (`src/MenuSystem.cpp:1563-1570`).

All facts with citations: `docs/original-code/front-end.md`.

## Key evidence (short)
* Logo: `if (canvas->pacLogoTime <= 120) { canvas->pacLogoTime++; … "l2.bmp" …}`
  (`src/GameStateRunner.cpp:332-337`); starts at -1 (`src/Canvas.cpp:60`), so 122 frames.
* Intro exit: `if ((app->game->hasSeenIntro && this->numEvents != 0) || …scrollingTextDone)`
  → `backToMain(false)` (`src/Canvas.cpp:834-839`).
* `backToMain(false)`: `playSound(1071, 1, 3, false); setMenu(MENU_MAIN)` (`src/Canvas.cpp:1403-1406`);
  `imgMainBG = loadImage("logo.bmp")` (`:1383`).
* Continue row: `if (app->game->hasSavedState()) { … addItem(…CONTINUE_ITEM…, 8, 22, 0, …) }`
  (`src/MenuSystem.cpp:1257-1261`).
* `case 10: // ACTION_DIFFICULTY  app->game->difficulty = (uint8_t)this->items[i].param; … startGame(true);`
  (`src/MenuSystem.cpp:3095-3099`).
* `startGame(true)` … `app->canvas->setState(Canvas::ST_CHARACTER_SELECTION);` (`src/MenuSystem.cpp:3603`).
* Yes: `setCharacterChoice(stateVars[0]); player->reset(); setState(ST_INTRO); disposeCharacterSelection();`
  (`src/IntroSequenceManager.cpp:625-630`).
* `disposeIntro` → `canvas->loadMap(canvas->startupMap, false, true)` (`src/IntroSequenceManager.cpp:135`).
* Save-exit: `case 25: saveState(7,…)` (`src/MenuSystem.cpp:3199-3201`) → `if (saveType & 0x4) backToMain(false)`
  (`src/Canvas.cpp:879-880`). Save & Quit: `saveState(67,…)` (`:3113-3115`) →
  `saveType & 0x40` → `app->shutdown()` (`src/Canvas.cpp:882-883`).

## Rewrite comparison (`new_src/`, as of 2026-11-03)

**Exists**
* `io/MenuData` parses **all** `menus.bin` rows. The main-menu rows (3, 4, 16, 18, 19, 26,
  27) are already accessible by id (`new_src/io/MenuData.h:73-80`). The id enum lists only
  in-game ids (`:11-30`) and the action enum lacks 6/7/8/10/22/23/27
  (`new_src/io/MenuData.h:46-54`).
* `core/MenuSession` has the `loadMenuItems(beg,count)` slicing as `addParsedRows`
  (`new_src/core/MenuSession.cpp:566-574`), `setYesNo`, a nav stack, and the
  BACKTOMAIN/SAVEEXIT/SAVEQUIT actions wired to `env_.backToMain` / `saveGame(7|67)`
  (`new_src/core/MenuSession.cpp:1634-1642`).
* `core/LoadingManager::boot(forceNewGame)` = `startGame(forceNewGame || !hasSavedState())`
  (`new_src/core/LoadingManager.cpp:28-31`). `startGame(true)` wipes and calls
  `loadMap(1,false,true)`, skipping character select and the prologue (`:33-52`).
  `--newgame` is parsed in `new_src/core/Main.cpp:45-66`.
* `backToMain` = quit (`new_src/core/GameContext.cpp:70`). The `ST_SAVING` exit bit 0x04
  also quits (`new_src/core/LoadingManager.cpp:182-185`).
* `SaveGame` writes/reads `difficulty` in the config (`new_src/core/SaveGame.cpp:150`).
  `hasSavedState()` exists (`:215`).
* `Player::setStatsAccordingToCharacterChoice` is ported (`new_src/domain/game/Player.cpp:162-190`).
  `characterChoice` defaults to 1 (`new_src/domain/game/Player.h:105`) and round-trips in
  the save (`new_src/domain/game/PlayerState.cpp:59,131`).
* `core/MayaCamera` exists (used by cinematics). The ST_TRAVELMAP and ST_LOADING sessions
  and views exist.

**Missing / divergent**
1. No `ST_LOGO` 26, `ST_INTRO_MOVIE` 2, `ST_CHARACTER_SELECTION` 22, `ST_INTRO` 9 or
   `ST_CREDITS` 15 in `StateId` (`new_src/core/GameStates.h:10-24`).
2. No main menu: no `MENU_MAIN` / 13 / 14 / 16 screens and no main-menu skin (`logo.bmp`,
   `logo2.bmp`, `menu_button_background(_on).bmp`, `Menu_Dial(_Knob).bmp`,
   `Switch_Left_*`). `UiAssets` loads only in-game menu art
   (`new_src/ui/UiAssets.cpp:42-134`). No dial scrollbar or row snapping.
3. Difficulty is not stored in `Game`. `Game::difficulty()` reads `vm_->vars[12]`
   (`new_src/domain/game/Game.cpp:748-750`), which `GameContext` hard-stamps to 1 on every
   map load (`new_src/core/GameContext.cpp:529`; legacy stamps `game->difficulty`,
   `src/LoadingManager.cpp:692`). The DEFENSE-0 override for difficulty 2 is skipped
   (`new_src/domain/game/Player.cpp:148-149`).
4. `vars[14]` is hard-set to 1 in `ScriptVM::updateScriptVars`
   (`new_src/domain/game/ScriptVM.cpp:315-320`). It must become `player.characterChoice`
   (legacy `src/Game.cpp:3468`).
5. HUD portrait sheet is always `Hud_Player.bmp` (`new_src/ui/UiAssets.cpp:80`). Legacy
   swaps to `Hud_PlayerDoom` / `Hud_PlayerScientist` by choice (`src/App.cpp:439-450`).
6. No table-camera loader (`loadTableCamera(14,15)`, `src/Game.cpp:511-535`), no
   `prolog.bmp` pan and no scrolling-text crawl (0:133). No prologue pages (2:12).
7. No Exit-to-OS confirm (13) and no Credits state.
8. Title music 1071 / intro music 1068: the rewrite only logs sound ids.

## Suggested implementable split
1. **G1, difficulty + choice plumbing** (no UI). Store `difficulty` on `Game` (default 1,
   load/save via config). Stamp `vars[12]` from it. Stamp `vars[14]` from
   `player.characterChoice`. Apply the DEFENSE-0 override in `Player::reset`. Pick HUD
   faces by `characterChoice`.
2. **G2, main-menu screens in `MenuSession`** (data already parsed): `MENU_MAIN` 3 with
   Continue + the `(0,2)+(3,-1)` slicing, `MENU_MAIN_EXIT` 13, `CONFIRMNEW` 14,
   `DIFFICULTY` 16 (`(1,-1)`, select index 1), `MAIN_HELP` 4 (`(1,-1)`) + help leaves.
   Actions 7/8/10/22. `startGame(true)` / `startGame(false)` via `LoadingManager`. Real
   `backToMain`: unload map, reset player, open `MENU_MAIN`. Replace the boot auto-continue
   and the quit stand-ins (supersedes ADR 0037 §6).
3. **G3, main-menu skin in `MenuView`**: `logo.bmp` + `logo2.bmp`, 204×38 button plates
   at x 138 with 46-px rows in the (138,126,204,176) window, dial scrollbar with row
   snapping, `Switch_Left` Back soft key.
4. **G4, character select** (`ST_CHARACTER_SELECTION` 22): assets, layout §8.3, keys +
   touch §8.4, choose → `reset()`.
5. **G5, prologue** (`ST_INTRO` 9): 2:12 with name arg, gameHelpBG, Back/More/Skip/Continue,
   end → `loadMap(1,false,true)`.
6. **G6, boot presentation**: `ST_LOGO` (l2.bmp, 122 frames) and `ST_INTRO_MOVIE`
   (table camera 14/15 over prolog.bmp, 1500 ms fade-in, 0:133 crawl at 20 px/s, any-key
   skip). These are optional and can come last.
7. Deferred: Mini Games from the menu (18; minigames already exist), Comic Book (89),
   Credits (15), the `[GEC]` Options body.
